# Widget Pro User Manual

## Getting Started

Welcome to Widget Pro. This manual explains how to install, configure, and
operate your device safely.

Before first use, charge the battery fully. The charge indicator turns green
when charging is complete.

## Installation

1. Unpack the device and check that all parts are present.
2. Connect the power adapter to the port labeled `PWR`.
3. Press and hold the power button for three seconds.

```bash
# Verify the firmware version from the command line
widgetctl --version
```

## Safety Warning

Do not expose the device to water. Contact with liquid voids the warranty.
